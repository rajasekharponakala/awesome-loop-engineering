# Contributing

Thanks for helping keep this list useful.

## Scope

This list covers loop engineering in its AI coding-agent sense only: systems that discover
work, delegate to agents, verify results, persist state, and re-run without a human in the
inner loop.

Do not open a PR for: software event loops, UI or game loops, growth loops, generic workflow
automation, or non-AI feedback loops.

## Entry format

- `- 📄 [Title](https://example.com) — Annotation.`

The type marker is one of: 📄 Paper, 📝 Essay, 📖 Guide, 🛠 Runtime/Tool, 🎥 Talk, 📦 Template,
📚 List.

## Rules

- The annotation is at most 15 words and says what the reader gets, not what the thing is.
- Prefer primary sources over aggregators. No marketing copy or unsupported superlatives.
- One entry per idea. If two entries overlap, keep the stronger one.
- Every URL must be live when you open the PR.
- The ten sections are a curated spine. If an entry fits none of them, say why in the PR
  description rather than forcing it in.
